[یادداشت رسمی ۱٫۱۳۷](https://code.visualstudio.com/updates/v1_137) تاریخ ریلیز را **۹ سپتامبر ۲۰۲۶** گذاشته. تیتر مایکروسافت این است که ویرایشگر کار تکراری را زمان‌بندی می‌کند، چت سریع را بدون از دست دادن تاریخچه به پروژه وصل می‌کند، با عامل حرف می‌زند، و Issue/PR گیت‌هاب را از پنجرهٔ Agents می‌خواند. رول‌اوت تدریجی است؛ Check for Updates را خودتان بزنید.

این نسخه کمتر «تم جدید، کلید جدید» است و بیشتر ویرایشگر را به **میزبان عامل** تبدیل می‌کند.

## Automations؛ کار تکراری که نباید هر بار از نو شروع شود

با `chat.automations.enabled`، از نوار Agents بخش Automations باز می‌شود. قالب آماده برای catch-up روی تغییرها، triage مسئله، یا پیدا کردن باگ هست؛ یا prompt و زمان‌بندی خودتان. اجرا **ساعتی، روزانه، هفتگی**، یا فوری. وضعیت: Preview و رول‌اوت تدریجی. اگر منتظر بودید عامل «هر صبح PRهای باز را خلاصه کند» بدون این‌که خودتان چت را باز کنید، همین قابلیت است — هنوز پیش‌نمایش.

## Voice Mode حرف می‌زند؛ شما وسط کار قطعش می‌کنید

آزمایشی است: `agents.voice.enabled`. دکمهٔ Voice Mode روی ورودی چت. وقتی عامل حرف می‌زند، صحبت شما یا میانبر push-to-talk پاسخ را قطع می‌کند و مکالمه ادامه می‌یابد. از نشست فعال، مدل انتخاب‌شده و فایل‌های پیوست خبر دارد؛ می‌تواند نشست تازه شروع کند و اعلام می‌کند درخواست به نشست موجود می‌رود یا به نشست جدید.

محدودیت را خود صفحه نوشته: رول‌اوت تدریجی، نیاز به پلن فردی واجد شرایط GitHub Copilot، **روی Copilot Business/Enterprise نیست**، و سازمان می‌تواند پیش‌نمایش را با policy ببندد. صدا، میکروفون و نمایش رونوشت تنظیم جدا دارند (`agents.voice.voice`، `agents.voice.showTranscript`).

## چت بدون پروژه، بعد همان تاریخچه داخل پوشه

می‌شود در Agents بدون workspace حرف زد. وقتی بحث به پروژه رسید، از عامل بخواهید پوشهٔ محلی را بچسباند. بعد از تأیید — استفادهٔ مستقیم از پوشه یا worktree جدا — همان نشست عنوان، تاریخچه و درخواست جاری را نگه می‌دارد و با دسترسی به فایل‌ها ادامه می‌دهد. فعلاً فقط در Copilot harness.

وقتی عاملی با ابزار `send_message` به چتی که مشغول است پیام می‌دهد، VS Code پیام را صف می‌کند و بعد از تمام شدن نوبت موفق، به ترتیب می‌فرستد — چند عامل موازی بدون قطع حرف همدیگر.

**Agent host** نشست را در پروسهٔ جدا روی Agent Host Protocol (AHP) نگه می‌دارد تا از چند پنجره به همان نشست وصل شوید. عامل Copilot این میزبان با Copilot SDK است؛ رفتار با Copilot CLI و اپ جدا تراز می‌شود. هنوز در حال توسعه.

## Issue و PR بدون عوض کردن پنجره

با نصب افزونهٔ GitHub Pull Requests و `extensions.experimental.enableAgentsWindowCapability`، لینک `github.com` مسئله یا PR داخل Agents باز می‌شود — حتی اگر workspace آن مخزن باز نباشد. از منوی Add Context در هر ورودی چت هم می‌شود Issue/PR چسباند. چسباندن URL در ورودی نشست تازه، هم متن را نگه می‌دارد هم attachment می‌سازد.

دو تغییر کوچک diff که به کار بررسی پچ چندفایلی می‌آید: layout Inline / Side by Side / Automatic از یک منو برای diff معمولی، چندفایلی و Changes در Agents؛ و فایل باینری دیگر از diff چندفایلی حذف نمی‌شود — جای‌نما «Binary file changed»، بعد Open Diff.

اگر ۱٫۱۳۶ را برای عامل نگه داشته‌اید، ۱٫۱۳۷ همان نسخه‌ای است که زمان‌بندی، صدا و GitHub را داخل همان پنجره آورد — هر سه هنوز با برچسب Preview یا Experimental.
